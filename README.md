# ENS Components v2

Monorepo for [`@thenamespace/ens-components-v2`](./packages/ens-components) and
its [documentation and demo app](./apps/demo).

## Development

Install dependencies and start the package and demo in development mode:

```sh
pnpm install
pnpm dev
```

Run all repository checks with:

```sh
pnpm check
```

Build every workspace package with:

```sh
pnpm build
```
